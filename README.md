# Credit Risk Analysis Using Python

## About the Project
This project analyses loan applicant data to identify patterns associated with loan defaults. It uses Python for data cleaning, exploratory data analysis (EDA), statistical analysis and visualisation.

## Objectives
- Analyse loan applicant data.
- Handle missing values using median imputation.
- Study loan default and non-default patterns.
- Compare loan grades, income, loan amounts and interest rates.
- Analyse previous default history.
- Visualise relationships using charts and heatmaps.

## Dataset
- **File:** `credit_risk_dataset.csv`
- **Records:** 32,581
- **Columns:** 12
- **Target Column:** `loan_status`
  - `0` – Non-default
  - `1` – Default

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Findings
- 78.18% of loans are non-default and 21.82% are default.
- Loan Grade G has the highest observed default rate (98.44%).
- Defaulted loans have a higher average interest rate (12.87%).
- Applicants with previous default history have a higher observed default rate (37.81%).
- Loan-to-income percentage has the strongest positive correlation with loan status (0.379).
