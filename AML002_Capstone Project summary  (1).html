What is a Data Science project?

A structured way to answer a real question using data, analysis and clear reasoning.

AML002 · Introduction to Data Science · Capstone Assignment

3

REAL-WORLD PROBLEM

Example: Why do some students score higher than others?

DATA + METHODS

Attendance, study hours, assignment marks and grades; Python, Pandas and charts.

USEFUL OUTCOME

Find patterns and communicate evidence. Prediction is optional when it does not fit the question.

Key message: the goal is not to write the most code — it is to answer a meaningful question responsibly.

PHASE 2 · 20 MARKS

Clean, wrangle and explore

Good analysis begins with checking data quality — not assuming the data is perfect.

AML002 · Introduction to Data Science · Capstone Assignment

7

CHECK QUALITY

  • • Missing values
  • • Duplicate rows
  • • Incorrect data types
  • • Inconsistent labels
  • • Unusual values / outliers

USE PANDAS

df.isnull().sum()
df.duplicated().sum()
df.describe()
df['column'].value_counts()
Choose a treatment and explain why.

ASK QUESTIONS

  • • Which group has a higher average?
  • • Are values spread out?
  • • Are there unusual observations?
  • • What patterns need a chart?

Important: never delete or replace data blindly. Explain the decision you make.

PHASE 3 · 20 MARKS

Visualise data and explain insights

A chart is useful when it answers a question — not just because it looks attractive.

AML002 · Introduction to Data Science · Capstone Assignment

8

CHOOSE A CHART

Bar chart → compare groups
Histogram → distribution
Scatter plot → relationship
Line chart → change over time
Box plot → spread / outliers

MAKE IT READABLE

  • • Descriptive title
  • • Labelled axes
  • • Units where needed
  • • Readable scale
  • • Avoid unnecessary decoration

INTERPRET IT

  1. Write 2–3 sentences:
  2. 1. What do you observe?
  3. 2. What does it suggest?
  4. 3. What are the limitations?

Example: Compare average marks across attendance groups, then describe the observed pattern carefully.

PHASE 4 · 20 MARKS

Machine Learning — only when it fits

Use a model when your question genuinely involves prediction or another suitable learning task.

AML002 · Introduction to Data Science · Capstone Assignment

9

FIRST DECIDE

What are you predicting?
Target = the outcome
Features = information used to predict it
Avoid using information that would not be available at prediction time.

THEN BUILD

  • • Split training and test data
  • • Choose a suitable algorithm
  • • Train using training data
  • • Predict on held-out data
  • • Compare with a baseline where useful

EVALUATE

Classification: accuracy, precision, recall, confusion matrix
Regression: MAE, RMSE or R²
Choose metrics that fit the task.

If prediction is unsuitable for your project, discuss an approved analytical alternative with your faculty.

WORKED EXAMPLE

Mini-project: Student Performance Analysis

A small, beginner-friendly example that follows the same project workflow.

AML002 · Introduction to Data Science · Capstone Assignment

16

PROBLEM + OBJECTIVE

Problem: Teachers want to understand how attendance and assignment scores relate to test marks.
Objective: Explore patterns in a small sample dataset.

SAMPLE DATA

Student | Attendance | Assignment | Test
Asha | 90% | 8/10 | 17/20
Ravi | 70% | 6/10 | 12/20
Meera | 95% | 9/10 | 19/20
Kabir | 60% | 5/10 | 10/20

INITIAL OBSERVATION

In this tiny example, students with higher attendance and assignment marks also have higher test marks.
This is an observed pattern only—not proof of cause.

import pandas as pd
df = pd.DataFrame({
"Student": ["Asha", "Ravi", "Meera", "Kabir"],
"Attendance": [90, 70, 95, 60],
"Assignment": [8, 6, 9, 5],
"Test": [17, 12, 19, 10]
})
print(df.head())
print(df[["Attendance", "Assignment", "Test"]].describe())

STUDENT TASK

  1. 1. Run the code in Colab.
  2. 2. Add a bar chart or scatter plot.
  3. 3. Write 2 observations and 1 limitation.
  4. 4. Explain what extra data could improve the study.

# Student Performance Analysis
## 1. Project Overview
This beginner project explores patterns between attendance,
assignment scores and test marks in a small sample dataset.
## 2. Research Question
How are attendance and assignment scores associated with test marks?
## 3. Dataset
A small illustrative dataset created for learning.
It contains Student, Attendance, Assignment and Test columns.
## 4. Tools
Python, Pandas, Matplotlib, Google Colab and GitHub.
## 5. Steps
- Load and inspect the data
- Summarise columns
- Create charts
- Record observations and limitations
## 6. Key Finding
In this small example, higher attendance and assignment scores
appear alongside higher test marks. This is not proof of causation.
## 7. Limitation
Only four sample records are used; results cannot be generalised.
